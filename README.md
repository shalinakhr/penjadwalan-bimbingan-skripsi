# Penjadwalan-Bimbibangan_Skripsi-Dosen_FEB-Undip
Proses penjadwalan bimbingan skripsi saat ini dilakukan secara informal melalui aplikasi Whatsapp tanpa adanya sistem terpusat. Secara formal, UNDIP telah menyediakan sistem informasi akademik bernama SIAP Undip yang biasanya digunakan untuk pencatatan aktivitas bimbingan dan pengelolaan data tugas akhir.
